# SFL BIDDING WEBSITE

This website hosts the team auctions for an intra-college football league known as SFL. 

Credits for the original code and design go to Sandeep Chezhian ([@pinkmann300](https://github.com/pinkmann300)). 

Project taken over in 2024 by Aditya Swami ([@adityaswamii](https://github.com/adityaswamii)).  
The functionality was extended to the basketball league KBL and the cricket league KCL, all implemented in the various `/swami*` branches.
